# Second Line Jazz Practice

A small, dependency-free practice tracker for rock drummers learning the foundations of jazz drumming.

## Features

- Three focused beginner jazz exercises
- Detailed instructions and listening cues
- Per-exercise done and not-done status
- Progress that persists in the browser
- Responsive, keyboard-accessible interface

## Run locally

From this folder, start a static server:

```sh
python3 -m http.server 4173
```

Then open [http://127.0.0.1:4173](http://127.0.0.1:4173).

The app uses plain HTML, CSS, and JavaScript. It has no build step or external dependencies.
